03 이송·광전 현장 대응 절차

P01 / P06 - 늦거나 나오지 않는 트레이
운영자는 추가 투입을 사업장 절차에 따라 보류하고, 트레이 위치와 후속 설비 수신 상태를 확인한다. 후속 미수신이면
후속 공정 책임자와 원인을 먼저 해소한다. 보전 담당자는 에너지 차단 후 가이드·연결부 간섭, 트레이 변형, 벨트 상태·
장력·동력 전달부를 확인한다. 전기 담당자는 실제 회전·드라이버 알람과 출구 센서 표시/PLC 입력을 대조한다. 벨트가
돌거나 RPM이 높다는 사실만으로 트레이가 정상 이동했다고 판단하지 않는다.
P03 / P04 - 센서 장기 점유
센서 앞 물체 유무와 실제 출력 상태를 먼저 대조한다. 실제 점유면 입구 밀착 투입·출구 인계·기계 간섭을 점검한다. 물
체가 없는데 점유가 지속되면 감지면 오염, 광축·감도, 장착 풀림, 배선·극성·입력 매핑을 확인한다. 렌즈 세척·조정·교환은
해당 모델 절차에 따른다. 주변 센서 간 광 간섭과 외란광도 확인 대상이다. [R1]
P02 / P05 / P07 - 빠른 이송·주기·변동
제어 담당자는 목표속도·감속비·벨트 이송 조건·투입 프로그램 변경을 확인한다. 속도가 정상인데 짧은 T가 나오면 먼저
FIFO 대응과 원천 에지 누락을 조사한다. 주기가 5초와 다르면 상위 설비 공급·대기·트레이 간격 변화도 확인한다. 정상
적인 조건 변경이면 프로파일을 개정하고 다른 조건의 로그를 섞지 않는다.

| 관측 대조 | 가능성이 높아지는 후보 / 추가 확인 |
| --- | --- |
| 트레이 정체 + RPM 저하 + 입력전류 상 승 | 기계 저항·과부하 후보. 지정 전류 데이터로 이 결론을 재현했다고 주장하지 않는다. |
| 트레이 정체 + RPM 정상 | 벨트 미끄러짐·동력 전달 문제·트레이 간섭 후보. 회전 계측 위치와 실제 벨트 움직임 확인. |
| 실제 정상 배출 + 출구 미검출 | 출구 센서·PLC 입력·에지 수집 문제 후보. 물체 존재 논리·표시등·수집 순번 대조. |
