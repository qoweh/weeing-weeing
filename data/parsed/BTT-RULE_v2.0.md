## 페이지 1

| BATTERY TRAY TRANSFER / BAT-TRANSFER-01 |
| --- |
|  |

배터리 트레이 이송 공정
룰베이스 최종 정의서
1개 공정 · 7개 센서 모듈 · 15개 입력 컬럼

> 문서 기준 BTT-RULE v2.0 / 데이터 스키마 3.0.0 공정 BAT-TRANSFER-01 / 설비 BLDC-001 작성일 2026-10-19 / 용도: 구현·시연 및 현장 검증 기준안

사용자가 제공한 A/B/C 범위와 이송시간·투입주기를 반영하고, 경계값·지속시간·결측·기동·다중 트레이 추적의 판단 방식
을 명시했다. 두 번째 문서의 대응 매뉴얼과 동일한 에러코드를 사용한다.
최신 요청 반영: 전류의 빈 값 60개는 정상 범위의 중앙값 0.0918745 A, 외함 온도의 빈 값 60개는 중앙값 65.0℃로 지정
했다. 이는 시연용 지정값이며 실측·추정 복원값이 아니다.
상태: 문서 최종안. 설비별 보호 한도 및 제어 연동은 현장 검증 전이며, 이 문서의 Error는 실제 고장 확정이나 제조사 보
호 알람을 의미하지 않는다.
구성
01 적용 범위와 원칙 / 02 데이터 계약 / 03 판정 상태 / 04 수치 임계값 / 05 운전 조건·구동부 / 06 광전 이벤트 / 07 이
송 이상 / 08 진동·복합 판단 / 09 데이터 검증 / 10 인수시험·이력 / 11 출처

## 페이지 2

01 적용 범위와 판정 원칙
공정은 입구 감지 → 컨베이어 이송 → 출구 감지로 정의한다. S01/S02는 물체 점유, S03은 회전, S04는 DC 입력전류·버
스전압, S05는 외함 온도, S06/S07은 DE/NDE 진동 특징을 담당하는 논리적 모듈이다. 실제 장치 모델·장착 위치는 설치
문서에서 확정한다.

| 구분 | 최종 정의 |
| --- | --- |
| 사용자 제공 기준 | 수치 A/B/C는 그대로 보존한다. 정상 이송시간은 14~16초, 기본 투입주기는 5초다. |
| 설계 제안 | 지속시간, 회복시간, 주기 허용오차, 점유 제한시간, 변동성 기준 및 코드 번호는 현장 검증을 위한 초기 설정 이다. 공인 규격값이 아니다. |
| 관측과 진단 | 출구 미검출·RPM 저하·진동 증가를 먼저 보고하고, 걸림·미끄러짐·베어링 문제는 원인 후보로 표시한다. |
| 입력 범위 | CSV 15컬럼을 유지한다. RUN 지령·속도 설정·대기 상태·센서 건전성은 외부 PLC 문맥 또는 버전 관리 설정으 로 연결한다. 없는 문맥을 추측해 채우지 않는다. |
| 현재 데이터 용도 | 합성 광전값 및 검증되지 않은 계측 가공값을 담은 시연용 자료다. 정상 범위 승인·예지 성능·실제 고장 진단 의 실증 자료로 사용하지 않는다. |
| 안전·정지 | 모니터링 Error만으로 비상정지·자동 재기동을 수행하지 않는다. 검증된 PLC 인터록·안전 기능이 정지와 재기 동을 관리한다. |

수정한 단정 표현
“5초 외 주기 = 센서 고장”은 “투입 주기 이탈”로, “14초 미만 = 모터 고장”은 “빠른 이송 또는 추적 오류 후보”로 바꾼다.
계속 False는 물체 미투입·계획 정지·미검출, 계속 True는 실제 점유·센서 고정출력 등 여러 원인이 가능하다. [R1]

## 페이지 4

03 등급·지속시간·회복 조건

| 수치 구간 | 즉시 후보 상태 |
| --- | --- |
| B < A하한 <= A상한 < C | 모든 수치 설정이 이 순서를 만족하는지 먼저 검증 |
| A하한 <= x <= A상한 | Normal |
| B < x < A하한 | Warning-L |
| A상한 < x < C | Warning-H |
| x <= B 또는 x >= C | Error-L / Error-H: 범위의 하·상한 이탈 |
| 유효 입력 또는 필수 문맥 없음 | Unknown: 해당 룰 판정 불가 |
| 정상 정지·대기·예열 등 승인된 제외 조건 | Suppressed: 평가 억제. 억제 사유는 기록 |

시간 확정 방식 - 초기 설정 제안
RPM·전류·진동의 Warning/Error는 같은 등급 이상·같은 방향 조건이 연속 3초일 때 확정한다. 전압은 1초, 온도는 10초
로 제안한다. 1초 표본에서 3초 지속은 첫 표본과 마지막 표본 차이가 3초인 4개 표본이다. 단발 값은 후보로만 저장한
다.
Error가 활성화된 뒤 값이 Warning 영역으로 돌아오면 Error는 회복 대기로 유지한다. A 안에서 연속 10초 정상일 때 해
제한다. Warning도 A 안 연속 10초 후 해제한다. 반대 방향 이탈은 새 후보로 추적하고 활성 사건 이력에 함께 남긴다.
결측·시간 공백 발생 시 연속성 타이머를 끊고 Unknown으로 표시한다. 이미 발생한 Error 사건은 미해결 상태로 남기며
데이터가 없다는 이유로 회복 처리하지 않는다. 경과시간은 표본 개수가 아니라 timestamp 차이로 계산한다.

> 등급과 조치는 분리한다. 저온·낮은 RMS·낮은 첨도의 Error는 “설정한 관측 범위 이탈”이다. 기계 파손이나 중대 위험 의 확정을 의미하지 않으며 자동 정지 조건으로 사용하지 않는다.

## 페이지 5

04 수치 룰 임계값 원장

| 모듈 / 데이터 | A 정상 | B 이하 | C 이상 | 코드 하/상 |
| --- | --- | --- | --- | --- |
| S03 rpm (rpm) | 1,000 ~ 1,030 | 990 | 1,040 | M02 / M03 |
| S04 dc_input_current_a (A) | 0.089963 ~ 0.093786 | 0.080967 | 0.103165 | M05 / M06 |
| S04 dc_bus_voltage_v (V) | 20.0 ~ 25.0 | 18.0 | 27.0 | M07 / M08 |
| S05 motor_housing_temp_c (℃) | 45 ~ 85 | 40 | 90 | M09 / M10 |
| S06 de_vibration_rms_g (g) | 0.040396 ~ 0.080601 | 0.036356 | 0.088661 | M11 / M12 |
| S06 de_kurtosis (-) | 3.5511 ~ 7.0661 | 2.8836 | 7.7727 | M13 / M14 |
| S07 nde_vibration_rms_g (g) | 0.049179 ~ 0.062322 | 0.044261 | 0.068554 | M15 / M16 |
| S07 nde_kurtosis (-) | 3.3565 ~ 5.4770 | 2.7413 | 6.0248 | M17 / M18 |

표의 M 코드는 모두 BTT2- 접두사를 붙인다. 예: BTT2-M02. 같은 코드의 severity를 Warning 또는 Error로 기록하므로
Warning 전용 번호를 중복 생성하지 않는다. A/B/C 숫자는 사용자 제공값이며 제조사 고장 검출 한도나 공통 산업 표준
이 아니다.
경계값 예시
RPM 990은 Error-L, 995는 Warning-L, 1000·1030은 Normal, 1035는 Warning-H, 1040은 Error-H 후보이다. 전류
0.080967 A와 온도 90℃는 각각 하한·상한 Error 후보에 포함된다. 지속시간을 만족해야 사건을 확정한다.
측정 조건의 제한
진동 g 값은 가속도 RMS이며 다른 단위의 진동 속도 허용치로 직접 대체하지 않는다. 첨도는 Pearson(정규분포 기준 3)
과 초과첨도(기준 0)를 혼용하지 않는다. 대역·축·원시 샘플링·특징 창 길이가 다르면 본 임계값의 직접 비교를 중지한다.

## 페이지 6

05 운전 조건·모터 구동부 룰
필수 외부 문맥: run_cmd, run_started_at, 운전모드, 목표속도 또는 recipe_id, planned_hold, downstream_ready, 정비모
드, 센서 유효성. 15컬럼에 새 컬럼을 넣지 않고 PLC 어댑터·설정 저장소에서 연계한다. 문맥 유효기간을 초과하면
Unknown으로 처리한다.

| 코드 | 조건·초기 설정 제안 | 제외·주의 |
| --- | --- | --- |
| BTT2-M01 | RUN 전환 뒤 3초 시점에도 rpm < 1000이면 기동 미도달. 기동 완료 후 run_cmd 유지 중 rpm <= 100이 3초 지속되 면 운전 중 정지 후보. | 3초는 사용자 기동 조건. 100 rpm·정지 3초는 설 계 제안. 정상 감속·정지 지령·대기는 제외. |
| BTT2-M02/M03 | 기동 유예 3초 이후 고정 속도 recipe에서 RPM 하한/상한 이탈. | 실제 목표속도 변경 시 별도 승인 프로파일 적용. M01과 동시 발생은 하나의 사건으로 묶는다. |
| BTT2-M04 | 정상 운전 20초 창의 rpm 최대-최소 > 30 rpm이면 Warning. 60 rpm 초과이면 Error. 창 조건이 3초 유지. | 20초 창의 21개 유효 1초 표본 필요. 고정 목표속 도에서만 사용. 숫자는 설계 제안. |
| BTT2-M05/M06 | 전류 하한/상한 범위 이탈. 운전 3초 이후, 동일 속도·적재 조건에서 평가. | DC 입력전류를 상전류·실제 토크로 변환하지 않 는다. 단독으로 과부하 확정 불가. |
| BTT2-M07/M08 | 전압 하한/상한 범위 이탈. 유효 측정이면 운전 전후에도 평가 가능. | 드라이버 형식·측정 위치를 먼저 확인. 짧은 과도 전압은 1초 로그에서 누락될 수 있다. |
| BTT2-M09/M10 | 외함 온도 하한/상한 이탈. 저온은 정상 운전 10분 예열 이 후 평가하는 초기안. 상한은 예열 중에도 평가. | 주변 온도·예열 조건으로 저온이 정상일 수 있다. 외함·권선·드라이버 내부 온도를 구분. [R2] |

제조사별 보호 동작은 별도로 유지한다. 드라이버 실제 알람을 추가 수집할 경우 원래 코드·모델·매뉴얼 판본을 함께 저
장하며 BTT2 코드로 덮어쓰지 않는다.

## 페이지 7

06 광전센서 이벤트와 다중 트레이 추적
기본 이송시간 14~16초에 5초마다 투입하면 평균 약 3개, 순간적으로 약 4개의 트레이가 구간에 존재할 수 있다. 최근
입구 에지와 출구 에지를 단순 차감하면 서로 다른 트레이를 연결할 수 있다.

| 단계 | 정의 |
| --- | --- |
| 1. 상태 정규화 | 센서 Light-ON/Dark-ON 또는 배선 극성에 관계없이 “물체 존재=true”로 변환한다. 최초 행이 true여도 새 진입 에지로 만들지 않는다. |
| 2. 원천 이벤트 | PLC에서 짧은 펄스를 포착하고 발생시각·순번을 보존한다. 1초 상태 표본만으로 누락 펄스가 없다고 보장할 수 없다. 디바운스는 최소 물체 통과폭보다 짧게 현장 설정한다. |
| 3. 초기 동기화 | 구간 비움 확인 또는 검증된 초기 재공 목록으로 시작한다. 현재 CSV는 초기 입구 true 및 기존 재공 여부 불 명으로 추적 미동기 상태다. |
| 4. FIFO 대응 | 분기·추월·역송·중간 투입/배출이 없는 공정에서 입구 상승 에지마다 가상 tray_seq를 큐에 넣고, 출구 상승 에지에서 가장 오래된 항목 하나만 꺼낸다. |
| 5. 시간 계산 | T = 출구 상승시각 - 대응 입구 상승시각. 14 <= T <= 16초가 정상. 경계값도 정상에 포함한다. |
| 6. 추적 실패 | 큐가 비었는데 출구 발생, 이벤트 순번 누락, 중복·역행, 공정 분기 발생 시 D04. 이후 이송시간 판정은 Unknown, 점유 관측은 유효하면 계속한다. |
| 7. 시간 초과 후 | 초과 트레이를 임의 삭제하지 않고 만료 표시로 남긴다. 늦은 출구는 대응 후보로 기록하되 누락 가능성 검 토 후 재동기화한다. 이후 트레이에 자동 전이하지 않는다. |


> planned_hold가 true이면 이송·주기 고장 판정을 억제하고 대기 시간을 별도 기록한다. 대기 해제 후 기존 추적이 유 효하면 재검증하고, 미확실하면 구간 비움 등으로 재동기화한다. 대기 전후 구간을 14~16초 기준 정상 통과 실적으 로 섞지 않는다.

## 페이지 8

07 이송 이상 룰·시간 기준

| 코드 / 의미 | 발생 조건·등급 | 판정·회복 |

P01 + M02 + M06이면 “이송 지연과 속도 저하·입력전류 증가 동반”으로 묶고 기계적 저항 후보를 먼저 확인한다. M07

우선순위: 데이터 유효성 확인 → 승인된 실제 드라이버 보호 알람 확인 → 전압·기동 및 이송 정체 → 진동·온도·추세. 원
