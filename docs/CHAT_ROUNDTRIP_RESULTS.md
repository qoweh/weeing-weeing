## 상태 변화와 품질 한계

4쌍의 상태가 달랐다.

- 온도 기준+이력 질문 1차: INSUFFICIENT_EVIDENCE → OK.
- 부품번호+재고 질문 2차: INSUFFICIENT_EVIDENCE → NEEDS_CLARIFICATION.
- 지시 대상이 없는 질문 1·2차: FAILED → NEEDS_CLARIFICATION.

이번 표본에서는 기존 OK가 후보의 비OK로 바뀐 쌍은 없었다.
계약·인용 존재·출처 최신 상태·근거 검토는 유지했지만, 모델 검토 통과와 서비스 OK가
사람의 사실 정확성 검수를 대신하지 않는다. 근거 부족/확인 질문 상태 선택의 적절성과
실제 답변 내용에 대한 사람 검수는 아직 수행하지 않았다. 운영 품질 비열등성이나
모든 질문의 10초 이내 응답을 달성했다고 해석하지 않는다.

## 실제 실행 기록과 재현

```bash
# 작업 폴더에서 실행. 기본은 무과금 계획 출력.
uv run --no-env-file --no-sync python scripts/benchmark_chat_roundtrips.py

# 실제 API 비용 발생. 같은 파일을 덮어쓰지 않으므로 새 출력 이름을 사용한다.
uv run --no-env-file --no-sync python scripts/benchmark_chat_roundtrips.py \
  --execute --repeats 2 --output outputs/chat_roundtrips/new-comparison.jsonl

# 가짜 LLM으로 전체 검사. localhost 통합 테스트 실행 권한이 필요하다.
make check RUN='uv run --no-env-file --no-sync'
```

GitHub에서도 확인 가능한 [집계·요청별 수치·측정 코드 해시](evaluation/chat_roundtrips_20261105.json)를 함께 보관한다.

원시 계측 `outputs/chat_roundtrips/comparison-v9.jsonl`, 자동 표 `comparison-v9.md`와
집계 `comparison-v9.summary.json`은 로컬 전용 경로이며 Git 제외 대상이다.
위 명령으로 새 출력 파일을 생성할 수 있지만 과거 실행의 동일한 수치를 재현한다는 뜻은 아니다.
