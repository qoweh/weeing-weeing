## 적용 범위

겹치는 window는 독립 사건이 아니며 코드별 시험 실행은 3개다. 이 성능은 Unreal 합성 데이터에만 해당한다.
Warning 후 회복 전용 실행, 실제 공장 일반화, 운영 서버 부하에서는 미검증이다.
정확한 선행시간 평가에는 Detector 이벤트 기록이 필요하다. 빈 라벨 시작을 실제 Error 시각으로 해석하지 않았다.
확률은 보정하지 않은 모델 예측 확률이다.
