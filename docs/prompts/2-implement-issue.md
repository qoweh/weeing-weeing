# 2단계: 이슈 구현 프롬프트

[1단계](1-plan-issue.md)에서 만든 하위 이슈 하나를 구현한다. 이슈마다 새 세션에서 실행한다.

```
이슈 #<번호>를 구현해 줘.

- 이슈 본문과 CLAUDE.md 규칙을 먼저 읽어 줘. 브랜치는 최신 origin/dev에서 만들어.
- 이슈에 없는 선택지가 생기면 임의로 고르지 말고 추천과 장단점을 붙여 물어봐.
- 테스트를 먼저 쓰고 구현해. 이슈 범위 밖은 고치지 말고 보고만 해 줘.
- 코드는 수정·확장이 쉽게, 불필요한 코드 없이, 읽기 쉽게 써 줘.
- 끝나면 make check를 통과시키고, 바뀐 것·검증 결과·남은 문제를 알려 줘.
  커밋과 PR은 내가 요청할 때만 해.
```
