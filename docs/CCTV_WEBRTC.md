# 공정 화면 영상 연결

대시보드는 같은 HTTPS 출처의 `/cctv-viewer`에서 영상을 표시한다. 웹 서버는
`/cctv/*` 요청을 내부 네트워크의 `weeing-cctv-udp-test:8889`로 전달한다.
이 중계기는 별도 관리하며 운영 웹 컨테이너와 같은 Docker 네트워크에 연결돼야 한다.
중계기나 송출이 중단되면 대시보드에 연결 대기 메시지가 표시된다.

발표 노트북에서는 OBS 영상을 SSH 터널로 중계기에 전달한다. 현재 시험 설정은
노트북 `127.0.0.1:19353`에서 서버 `127.0.0.1:19353`으로 연결하고, OBS 서버는
`rtmp://127.0.0.1:19353`, 스트림 키는 `cctv`다. 시청 브라우저는 서버의 UDP 8189로
직접 영상에 연결하므로 각 사용자 네트워크에서 해당 경로를 허용해야 한다.

`/cctv/*` 경로에는 별도 사용자 인증이 없다. 외부에서 주소를 아는 사람도 영상을
볼 수 있으므로 통제된 시뮬레이션 영상에만 사용하고, 실제 공장 영상은 인증 적용 후
공개해야 한다. 여러 명이 동시에 시청할 때의 성능과 지연은 실제 환경에서 확인한다.

중계기는 별도 컨테이너이므로 웹 배포만으로 설치되거나 포트가 열리지 않는다. 중계기
설정 변경이나 제거 전에는 담당자와 송출·시청 중 여부를 확인한다.
