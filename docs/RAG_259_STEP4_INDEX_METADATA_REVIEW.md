# #259 E2E 문서·쪽 및 청크 메타데이터 대조 기록

작성일: 2026-11-06. #259 본인 담당의 기대 문서·PDF 쪽을 사례별로 확정된 정답 v1과 대조하고, 저장소에 남아 있는 색인기 청크 메타데이터 캡처 및 PDF 화면을 확인한 기록이다. 색인 스냅샷을 새로 만들거나 운영 색인을 조회하지 않았다.

청크 감사 JSON은 **저장소의 색인기 출력 메타데이터 캡처**이며, 벡터 저장소의 지속 스냅샷이나 현재 운영 컬렉션 덤프가 아니다. 저장된 원본 청크 본문과 출처 해시를 대조할 수 있지만, 실제 운영/평가 컬렉션의 활성 상태·백업·복원은 이 자료만으로 증명하지 않는다. 청킹 방식에 따라 청크 ID와 페이지별 분할 개수가 달라지므로 아래 ID는 당시 해당 방식의 재현용 참조다.

## 사례별 청크 ID 대조

각 ID는 저장된 감사 캡처에서 해당 문서·페이지 메타데이터로 확인한 청크다. 한 페이지가 여러 청크로 나뉘거나, legacy와 structured에서 ID가 달라질 수 있다.

## 완료 판단

- 관련 PDF 쪽의 시각 확인을 끝냈다. 페이지 번호·표 행·적용 문맥은 앞서 추출한 PDF 본문과 일치한다.
- 승인된 정답 v1의 문서·쪽 및 사례의 사건/센서 입력을 청크 캡처와 대조했다. E05 합성 보고서와 E07 가상 구버전은 이 캡처에 없으며, 승인 정답에서도 각각 비교용 자료와 유효 판본 정책으로만 사용한다. 실제 보고서·구버전 fixture를 이미 색인된 것처럼 기록하지 않았다.
- **4번의 문서·쪽·기존 청크 메타데이터·페이지 시각 검토 및 승인 입력 대조를 완료**했다. 현재 쓰는 실제 평가/운영 벡터 컬렉션의 ID와 복원 가능성을 입증할 지속 스냅샷은 별도 평가 환경에서 생성해야 한다. 이는 [5단계 스냅샷 방법](RAG_259_STEP5_SNAPSHOT_METHOD.md)에 따라 평가 담당자에게 인계한다.
- 50~80% 난이도 통과율은 실행 전이며 이 문서에서 측정하지 않았다.
