## 실행 전 고정할 공개 설정

아래 값은 **미확정**이다. 운영과 같은 설정으로 난이도를 확인하려면 평가 담당자가 실제 실행 설정을 확인해 비밀값 없이 기록한다. 사용자 요청의 API 모델 후보는 Voyage 임베딩 `voyage-4-lite`, 리랭커 `rerank-3-lite`이며, 실제 접근 가능 여부와 최종 선택은 아직 확인하지 않았다.

## 확정 조건

1. 팀과 실행 커밋 및 격리 평가 환경을 결정한다.
2. 원본과 복원 대상이 운영 데이터와 분리되어 있는지 담당자가 확인하고 비밀 없는 식별자를 기록한다.
3. 검색·모델 공개 설정과 문서·사례·gold 해시를 실행 대상에서 다시 확인한다.
4. 이후 실제 fixture·색인 생성과 스냅샷 복원 결과를 [잔여 실행 체크리스트](RAG_259_STEPS1_8_REMAINING_EXECUTION.md)에 연결한다.

설정이 정해지기 전에는 1번을 완료로 표시하지 않는다. API 키, 인증 정보, 환경 전체 값은 기록하거나 공유하지 않는다.

## 평가 담당자에게 확인할 사항

- 실행할 커밋 SHA와 해당 커밋에 적용할 사례·gold 버전.
- 평가 전용 DB·벡터 저장소의 제품과 비밀이 아닌 식별자. 원본·복원 대상이 각각 운영 환경과 분리되어 있는지.
- 운영과 동일한 난이도 측정에 사용할 모델·차원·후보 수·최종 K·하한 및 필터 등 공개 설정.
- fixture 적재, 백업·복원과 평가 실행의 담당자 및 사용할 평가 환경.

확인 결과를 받은 뒤 이 초안을 갱신한다. 설정을 임의로 운영값이라 단정하거나 snapshot ID를 확정하지 않는다.
