# 독립 질문셋 검색 재평가 (API 비사용)

## 범위와 재현성

- 질의 20개: 근거가 있는 질문 12개, 제공 문서에 답이 없는 질문 8개.
- 기존 `rag_queries_v1.toml` 및 `rag_queries_holdout_v1.toml`과 질문 문장 중복은 없다. 정답 키워드 12개 모두 실제 PDF를 구조 기반 청킹한 결과에서 확인했다.
- 독립성은 **질문 문장 기준**이다. 같은 세 문서와 설비 영역을 사용하므로 문서·주제까지 독립인 외부 검증셋으로 해석하면 안 된다.
- 실제 Claude·Voyage API 및 `.env`를 사용하지 않았다. 프로세스 설정을 해시 임베딩, Kiwi BM25, 리랭커 없음, 관련도 하한 없음으로 고정했다.
- 임시 Qdrant에 세 문서를 구조 기반으로 새로 색인했다. 후보 30개를 검색하고 상위 5개를 평가했다. 색인·멱등·버전 갱신 검사는 통과했다.
- 자세한 질의별 상위 청크는 [검색 실행 원본](../../outputs/rag_e2e/report-2026-11-04-independent-v2-retrieval.md)에 기록했다.

## 검색 기준선

정답 청크는 질의별 기대 문서와 본문 키워드로 이진 판정했다. Recall@K, MRR@5, nDCG@5는 각 12개 답변 가능 질문에 대해 Python으로 계산했다. nDCG는 단일 정답 청크의 이진 관련도 기준이다.

| 방식 | Recall@1 | Recall@3 | Recall@5 | MRR@5 | nDCG@5 |
|---|---:|---:|---:|---:|---:|
| Dense | 0.167 (2/12) | 0.500 (6/12) | 0.667 (8/12) | 0.333 | 0.416 |
| Hybrid (dense + Kiwi BM25) | 0.250 (3/12) | 0.583 (7/12) | 0.750 (9/12) | 0.440 | 0.518 |

Hybrid는 dense보다 상위 5개 정답이 1건 많고 MRR·nDCG도 높았다. 다만 답변 가능 질문 12개 중 3개는 상위 5개에서 정답 청크를 찾지 못했다. 표본이 작고 임베딩은 현재 기본인 hashing이므로, 과거 BGE 임베딩·리랭커 결과와 직접 비교할 수 없다.

## 답변 근거가 없는 질문

8개 모두 상위 5개 후보를 반환했다. 이 실행은 리랭커와 관련도 하한을 꺼 둔 검색 기준선이므로, **후보가 반환됐다는 사실만으로 최종 답변의 오반환이나 환각이라고 판정할 수 없다.** 원본 E2E 보고서의 `오반환 8`은 결과가 비었는지 세는 기존 지표이며, 이 구성에서는 실제 답변 가능성·안전 거절 여부를 평가하지 않는다. 반환된 청크를 직접 분류하거나 관련도 점수를 산출하려면 사용자가 별도 API 평가를 수행해야 한다.

## 다음 조치

- u03·u11·u12의 정답 청크 미검색 원인을 해당 상위 청크와 대조한다.
- 해시 임베딩 기준선만으로 전역 검색 설정을 바꾸지 않는다. API 없는 현재 코드에서는 Voyage 리랭커 전후 비교를 할 수 없다.
- 리랭커 기반 오반환 판정은 사용자가 로컬 터미널에서 비용·키 보호 규칙에 따라 실행한 결과가 준비된 뒤 별도 분석한다.
