# Qdrant·Chroma 실제 모델 관련도 필터 검증 — 2026-10-29

관련도 하한 `0.02`를 적용한 실제 모델 재실행에서 정상 질의의 검색 품질을 유지하고,
범위 밖 질의 6개 중 5개를 빈 결과로 거절했다. Qdrant와 Chroma의 집계 결과는 같았다.
단일 점수 기준으로 모든 범위 밖 질문을 분리하지는 못했다.
점수는 모델 관련도 척도이며 확률로 해석하지 않는다.

## 기준값 선택 근거

다음 표는 **기준 보고서에 소수점 4자리로 기록된 점수의 사후 계산**이다.
각 기준값마다 실제 모델을 재실행한 결과는 아니며, `0.02`만 별도로 실측 검증했다.
관련도 내림차순 결과에서 기준 미만을 제외하는 현재 필터 규칙을 적용했다.

|---|---|---|---|---|
| 0.01 | 30/30 | 0.869 | 4/6 | 없음 |
| 0.02 | 30/30 | 0.869 | 5/6 | 없음 |
| 0.03 | 30/30 | 0.869 | 5/6 | 없음 |
| 0.05 | 29/30 | 0.836 | 5/6 | q13 |
| 0.20 | 27/30 | 0.803 | 5/6 | q01, q13, q14 |

정상 질의의 반환 1위 점수 최솟값은 `0.0476`, 범위 밖 5개 질의의 반환 1위 점수는
모두 `0.0108` 이하였다. 그 사이의 보수적인 후보 `0.02`를 실측 검증했다.

## 남은 문제

- `o02`: “배터리 셀 화재의 소화약제 종류와 진압 절차는”에 SOP 조각
  `BTT-SOP-001:1.1:0007`이 관련도 `0.2810`으로 남았다. 요구한 소화약제·진압 절차의
  직접 근거는 평가셋에서 범위 밖으로 정의돼 있다.
- 이를 거절하도록 하한을 높이면 낮은 점수의 정상 질의도 제외된다. 이 평가셋에서
  단일 관련도 하한으로 정상 검색을 모두 유지하면서 모든 범위 밖 질의를 거절할 수는 없다.
- `0.02`는 이번 Qdrant·Chroma 평가의 후보값이다. 기준값 선택에 사용하지 않은 추가 정상·범위 밖
  질의로 검증해야 하며, 모델·문서·청킹이 바뀌면 다시 측정해야 한다.
- 실제 Claude 분석 흐름의 검증은 이번 실행 범위에 포함하지 않았다.
