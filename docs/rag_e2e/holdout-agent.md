# 새 질문 검증과 챗봇 근거 부족 응답 평가

새 질문에서 관련도 하한의 효과를 검증한 10-30 검색 평가와, 같은 근거 부족 사례에
대한 11-03 사용자 실행 챗봇 재평가를 통합했다.
검색 결과의 존재와 최종 답변의 근거 충족 여부를 나누어 평가한다.
보완 과제는 [평가 안내](README.md)에서 관리한다.

## 2. 실제 챗봇 o02 재평가 — 2026-11-03

사용자가 기존 `o02-validation` 평가 worktree에서 실행한 산출물을 검토했다.
이번 단일 재평가에서는 실제 검색 후 `INSUFFICIENT_EVIDENCE`로 종료했고,
요청한 소화약제·진압 절차를 근거 없이 생성하지 않았다.

| 항목 | 결과 |
|---|---|
| 질문 | 배터리 셀 화재의 소화약제 종류와 진압 절차는 |
| 요청·응답 모델 | `claude-haiku-5-5`, effort `medium`; 기록된 4개 응답 모두 요청 모델과 일치 |
| 검색 설정 | 기존 BGE 평가 구성, 구조 기반 청킹, 후보 30개·최종 최대 5개·하한 0.02 |
| 사전 검색 | 2개 반환, 1위 관련도 약 0.37364 |
| Agent 실제 검색 | 문서 4개 → 정비 이력 0개 → 문서 1개 |
| 최종 의도·상태 | `MANUAL / INSUFFICIENT_EVIDENCE`, 종료 코드 0 |
| 최종 문구 | 답변을 뒷받침할 근거가 충분하지 않습니다. |
| 본문·출처 | `parts=[]`, `sources=[]` |
| 내용 검토 | 약제·수치·진압 절차 등 근거 밖 주장 관측되지 않음 |
| 인용 정확도·정답 순위 | 해당 없음. 인용과 직접 정답 근거가 없어 100%나 순위 지표로 집계하지 않음 |

모델이 검색 없이 거절한 경우와 구분되는, 실제 검색 뒤의 근거 부족 응답 사례다.
단일 질문·단일 재평가 결과이며 다른 질문·반복 실행·HTTP 인증·대화 저장·화면의

## 도구와 코드 검증

- 새 질문 평가: `scripts/validate_rag_holdout.py`.
- 실제 챗봇 평가: `scripts/check_rag_agent.py`, 평가용 SQLite·Qdrant와
  `DatabaseChatKnowledge`·자유 대화 Agent 연결.
- 검색 조건·버전·출처 상태 검증은 `api/chat_knowledge.py`, 답변·근거 검토는
  `agent/chat.py`·`agent/chat_grounding.py`를 사용한다.
- FAQ ID 선택과 DB의 정비 이력 전체 건수 집계는 이 하한 평가와 다른 경로다.
- 10-30 당시 가짜 LLM을 이용한 연결 검증과 전체 검사 결과는 pytest 1,246개
  통과·6개 건너뜀, Ruff·포맷·스킬 동기화 통과다. 이후 전체 검사 상태를 뜻하지 않는다.

검색 원본은 로컬 `outputs/rag_e2e/holdout-2026-10-30-v1/`에 있다.
실행 도구 안내는 [RAG_HOLDOUT](../RAG_EVALUATION_GUIDE.md)을 참고한다.
실제 인증·유료 호출은 사용자가 직접 수행하며, 이번 문서 통합에서는 호출하지 않았다.
