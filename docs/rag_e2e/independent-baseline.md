# 독립 질문의 API 없는 검색 기준선

2026-11-04에 해시 임베딩과 Kiwi BM25로 검색 기준선을 측정했다.
리랭커·관련도 하한·Claude·Voyage API를 사용하지 않은 평가다.
과거 BGE 실측과 모델·질문이 달라 직접적인 성능 증감 비교에 사용하지 않는다.
후속 보완 항목은 [평가 안내](README.md)에서 관리한다.

## 입력과 평가 방식

- `data/eval/rag_queries_independent_v2.toml`: 정상 12개·근거 없음 8개, 총 20질문.
- 기존 본 평가·보류셋과 질문 문장 중복 없음. 동일 PDF 3종·설비 영역을 사용하므로
  독립성은 질문 문장 기준이다.
- 정답 키워드 12개 모두 실제 PDF의 구조 기반 청크 본문에서 확인했다.
- 해시 임베딩·Kiwi BM25, 리랭커 없음·하한 없음으로 고정했다.
- 임시 Qdrant에 구조 기반 청킹으로 새로 색인했다. 후보 30개·최종 K=5이며,
  색인·멱등·버전 갱신 검사를 통과했다.

## 검색 결과

정답 판정은 기대 문서·본문 키워드 기준이다. 원 보고서의 `Recall@K`는
단일 정답 가정에서 질문별 첫 정답 적중을 집계한 값이므로 여기서는 **Hit@K**로
표기한다. 수치는 바꾸지 않았다. nDCG@5도 첫 정답 하나에 이진 관련도를 부여한
대용 지표이며 전체 관련 청크·등급을 평가한 수치와 구분한다.

| 방식 | Hit@1 | Hit@3 | Hit@5 | MRR@5 | nDCG@5, 단일 정답 가정 |
|---|---:|---:|---:|---:|---:|
| Dense, 해시 벡터 | 2/12 | 6/12 | 8/12 | 0.333 | 0.416 |
| Hybrid, 해시 벡터 + BM25 | 3/12 | 7/12 | 9/12 | 0.440 | 0.518 |

Hybrid의 상위 5개 정답 적중은 Dense보다 1건 많았다.
순위 지표는 정상 12질문만 집계하며, 상위 5개에 정답이 없으면 0으로 계산한다.

## 근거 없음 질문의 해석

8질문 모두 상위 5개 후보가 반환됐다. 하한을 사용하지 않은 후보 검색 기준선이므로
이 결과는 최종 챗봇의 환각·안전 거절 지표가 아니다.
실제 답변 가능성은 반환 본문이 요청 정보를 담는지와 최종 응답을 함께 대조해야 한다.

당시 상세 상위 청크는 로컬
`outputs/rag_e2e/report-2026-11-04-independent-v2-retrieval.md`에 기록했다.
이 기준선만으로 전역 검색 설정이나 리랭킹 하한을 변경하지 않았다.
