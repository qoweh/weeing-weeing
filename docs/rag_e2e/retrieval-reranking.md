# 검색·리랭킹 성능 비교

2026-10-27의 검색·리랭킹 도입 평가와 10-29의 36질문·관련도 하한 검증을 통합했다.
모든 수치는 당시 BGE 임베딩·리랭커의 측정 기록이다.
현재 공급자 구성 및 후속 보완 항목은 [평가 안내](README.md)를 참고한다.

## 평가 구성

검색은 Dense와 한국어 Kiwi BM25의 후보를 RRF로 결합하고, 리랭커를 켠 경우
후보를 재정렬한 뒤 상위 5개를 반환한다. 관련도 하한을 적용하면 기준 미만을
제외한 다음 최종 5개를 선택한다.

| 항목 | 조건 |
|---|---|
| 문서 | `BTT-MANUAL` 2.0, `BTT-RULE` 2.0, `BTT-SOP-001` 1.1 |
| 입력 목록 | `data/eval/rag_documents_v1.toml` |
| 저장소 | 운영 색인과 분리한 Qdrant 로컬·Chroma 임시 저장소 |
| 임베딩 | `BAAI/bge-m3`, 정규화 |
| 리랭커 | `BAAI/bge-reranker-v2-m3` |
| 후보·반환 | 리랭킹 후보 30개, 최종 K=5 |
| 청크 | 기존 청킹 81개: 매뉴얼 28, 룰 21, SOP 32 |
| 정답 판정 | 기대 문서와 본문 키워드. 순위 지표는 정상 질문만 집계 |

10-29 실행은 CPU·캐시된 로컬 모델을 사용했으며 Claude를 호출하지 않았다.
임베딩 리비전은 `5617a9f61b028005a4858fdac845db406aefb181`,
리랭커 리비전은 `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`다.
실행 중 임베딩 재사용과 부하 차이가 있어 처리 시간을 백엔드의 속도 우열로 비교하지 않는다.

## 1. 검색 기준선 — 10-27, 12질문

Qdrant 로컬·Chroma·Qdrant 서버에서 같은 순위·집계 결과를 확인했다.
Qdrant 서버는 Docker `qdrant/qdrant:v1.20.0`를 사용했다.

| 방식 | Hit@1 | Hit@5 | MRR |
|---|---:|---:|---:|
| Dense | 9/12 | 12/12 | 0.822 |
| Hybrid | 7/12 | 12/12 | 0.743 |

이 표본에서는 두 방식 모두 상위 5개에 정답이 있었고, Hybrid의 1위 적중은
Dense보다 적었다. 코드 목록 표의 키워드 일치가 실제 대응 절보다 앞서는 사례를
확인해 이후 리랭킹 비교의 기준선으로 사용했다.

## 2. 리랭킹 도입 — 10-27, 18질문

기존 12질문에 Incident 코드 질문 6개를 추가했다. Qdrant·Chroma 결과는 같았다.

| 방식 | Hit@1 | Hit@5 | MRR |
|---|---:|---:|---:|
| Dense | 12/18 | 18/18 | 0.798 |
| Hybrid | 11/18 | 18/18 | 0.773 |
| 리랭킹 | 15/18 | 18/18 | 0.917 |

Hybrid 대비 리랭킹의 1위 적중은 4건, MRR은 0.144 높았다.
Incident 질문 6개는 리랭킹 후 모두 정답이 1위였다.
코드 질의문은 짧은 코드·이름·대응 문구를 결합하는 형태를 비교해 적용했다.
코드 필터를 기본 강제하지 않아 코드가 없는 SOP 절차도 후보에 포함했다.

## 3. 평가셋 확대와 관련도 하한 — 10-29, 36질문

`data/eval/rag_queries_v1.toml`의 정상 30질문(서술형·SOP 18개, 코드 12개)과
근거 없음 6질문을 사용했다. 빈 검색 결과만 검색 거절로 집계했다.

| 백엔드 | 방식 | 하한 | Hit@1 | Hit@5 | MRR | 근거 없음 거절 |
|---|---|---|---:|---:|---:|---:|
| Qdrant·Chroma | Dense | 없음 | 17/30 | 29/30 | 0.740 | 0/6 |
| Qdrant·Chroma | Hybrid | 없음 | 17/30 | 30/30 | 0.750 | 0/6 |
| Qdrant | 리랭킹 | 없음 | 23/30 | 30/30 | 0.869 | 0/6 |
| Qdrant·Chroma | 리랭킹 | 0.02 | 23/30 | 30/30 | 0.869 | 5/6 |

리랭킹은 Hybrid 대비 1위 적중 6건, MRR 0.119를 높였다. 하한 0.02 적용 시
정상 질문의 순위 지표를 유지하면서 근거 없음 질문 5/6개를 빈 결과로 전환했다.
필터 적용 실행의 36질문 × 3방식, 총 108건에서 두 백엔드의 정답 순위와
거절 결과가 같았다. Chroma의 하한 없는 리랭킹은 별도 측정하지 않았다.

### 관련도 분포와 하한 검토

하한 없는 Qdrant 실행에서 반환 1위 관련도 분포는 다음과 같았다.

| 질문 종류 | 수 | 최소 | 평균 | 최대 |
|---|---:|---:|---:|---:|---:|
| 정상 | 30 | 0.0476 | 0.7388 | 0.9886 |
| 근거 없음 | 6 | 0.0001 | 0.0504 | 0.2810 |

아래는 소수점 4자리로 저장된 점수에 대한 사후 계산이다.
이 중 **0.02만 별도 실제 실행으로 확인**했으며 나머지는 추정값이다.

| 하한 | 예상 Hit@5 | 예상 MRR | 예상 근거 없음 거절 | 제외되는 정상 질문 |
|---|---:|---:|---:|---|
| 0.01 | 30/30 | 0.869 | 4/6 | 없음 |
| 0.02 | 30/30 | 0.869 | 5/6 | 없음 |
| 0.03 | 30/30 | 0.869 | 5/6 | 없음 |
| 0.05 | 29/30 | 0.836 | 5/6 | q13 |
| 0.20 | 27/30 | 0.803 | 5/6 | q01·q13·q14 |
| 0.30 | 27/30 | 0.803 | 6/6 | q01·q13·q14 |

o01·o03·o04·o05·o06은 하한 0.02에서 빈 결과였다. o02는
`BTT-SOP-001:1.1:0007`이 관련도 0.2810으로 남았다. 관련 용어의 존재와
요청한 상세 절차의 존재를 구분하기 위해 [새 질문·챗봇 평가](holdout-agent.md)로 연결했다.

## 색인·갱신과 출처 검증

- 세 문서를 색인한 뒤 같은 입력의 재실행은 `unchanged`였다.
- 매뉴얼을 `2.0 → 2.0-e2e`로 바꾸면 이전 청크 0개·새 청크 28개가 됐다.
- 10-27에는 Qdrant 로컬·서버·Chroma에서 저장·갱신 결과가 같았다.
- 기존 81청크에서 페이지·인용 누락은 0개였다. 절이 없는 3개는 표지이며,
  코드가 없는 51개는 SOP 등 코드가 등장하지 않는 본문을 포함한다.
- 10-29 필터 실행의 초기 색인은 Qdrant 118.8초, Chroma 125.9초였다.
  각 실행에서 색인·멱등·갱신 검사를 통과했다.

## 구현·검증 연결

공개 검색 진입점은 `rag/interface.py`, 후보·필터·근거 변환은
`rag/retriever.py`, 모델 채점은 `rag/reranker.py`다.
평가 도구는 `scripts/verify_rag_e2e.py`이며 새 원본은 `outputs/rag_e2e/`에 저장한다.
10-29 코드 검증 기록은 Ruff·포맷·스킬 동기화 통과,
pytest 1,062개 통과·4개 건너뜀이다. 이 수치는 당시 검사 결과다.
