# 구조 기반 청킹 성능 비교

2026-10-30에 동일한 36질문·모델·하한으로 기존 청킹과 구조 기반 청킹을 비교했다.
구조 기반 청킹의 리랭킹 Hit@1은 23/30 → 24/30, MRR은 0.869 → 0.878이었다.
전체 평가 조건과 보완 항목은 [평가 안내](README.md)를 참고한다.

## 고정 조건

| 항목 | 조건 |
|---|---|
| 기준 코드 | `ab801fd2cfb445782b7a142d21ac300091be91c1`와 당시 평가 CLI 변경 |
| 입력 | 평가 PDF 3종, `rag_queries_v1.toml` 정상 30개·근거 없음 6개 |
| 모델 | `BAAI/bge-m3` / `BAAI/bge-reranker-v2-m3` |
| 모델 리비전 | [검색·리랭킹 보고서](retrieval-reranking.md)의 10-29 실행과 동일 |
| 청킹 크기·겹침 | 문자 기준 1,000 / 150, 표 행 보존 우선 |
| 구조 기반 처리 | 조항·사례 경계 인식, 문맥·제목 길이를 본문 가용 크기에서 차감 |
| 검색 | 후보 30개, 최종 K=5, 관련도 하한 0.02 고정 |
| 실행 | CPU, 문서 배치 8, 리랭킹 배치 2, Qdrant 로컬·Chroma의 독립 임시 저장소 |
| 캐시 | 실행 중 임베딩 재사용, 질의 임베딩 사전 계산 후 모델 참조 해제 |

실행 스레드는 OMP·MKL 각각 4개, `TOKENIZERS_PARALLELISM=false`였다.
캐시된 모델을 사용했고 후보 수·입력 길이를 줄이지 않았다.
캐시와 실행 부하가 포함된 시간을 청킹 방식·백엔드의 속도 우열로 해석하지 않는다.

## 질의별 리랭킹 순위 변화

Qdrant 상세 결과를 기준으로 비교했다. 아래 6개 외 정상 질문의 정답 순위는 같았다.

| 질의 | 내용 | 기존 순위 | 구조 기반 순위 |
|---|---|---:|---:|
| q01 | 입구 센서 감지 유지 | 2 | 1 |
| q06 | 구동측 진동 RMS 상한 | 2 | 1 |
| i08 | M03 RPM 상한 코드 | 3 | 1 |
| q16 | 에너지 격리 검증·기록 | 4 | 3 |
| q12 | 결측 시 룰 판정 | 1 | 4 |
| q13 | 모터 속도 과대 표시 | 1 | 4 |

코드 질문 12개의 Hit@1은 10/12 → 11/12, Hit@5는 12/12였다.
전체 MRR의 반올림 전 차이는 +0.00833이다.
같은 36질문은 하한 선택에도 사용했으므로 별도 검증셋 성능으로 해석하지 않는다.

근거 없음 o01·o03~o06은 두 청킹 방식·두 백엔드의 리랭킹 결과에서 모두 빈 결과였다. o02의 구조 기반
Qdrant 반환은 `BTT-SOP-001:1.1:0009`(0.3736),
`BTT-SOP-001:1.1:0029`(0.0239)였다. 하한·운영 기본값은 변경하지 않았다.

## 문맥 머리줄 영향 확인

같은 Indexer·입력으로 청크 본문을 재현해, 추가 `문맥:` 문단의 키워드만으로
정답 판정이 달라지는지 확인했다. 후보 청크는 q09의
`BTT-SOP-001:1.1:0005`, q10의 `0009`·`0010`이었다.
실제 Qdrant 반환 ID와 본문을 대조하고 문맥 문단을 제외해 재집계한 결과,
모든 정상 질문·검색 방식의 정답 순위와 집계는 유지됐다.

| 문맥 제외 재집계 | Hit@1 | Hit@5 | MRR |
|---|---:|---:|---:|
| Dense | 21/30 | 29/30 | 0.808 |
| Hybrid | 20/30 | 30/30 | 0.787 |
| 리랭킹 | 24/30 | 30/30 | 0.878 |

이 확인은 Qdrant 상세 반환을 대상으로 했다. Chroma 상세 반환과 전문가의 의미상
정답 판정을 대신하지 않는다.
