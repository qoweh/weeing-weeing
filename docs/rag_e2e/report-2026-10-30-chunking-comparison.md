# 기존·구조 기반 청킹 검색 품질 재평가 — 2026-10-30

동일한 36개 질의에서 구조 기반 청킹의 리랭커 Hit@1은 23/30에서 24/30,
MRR은 0.869에서 0.878로 소폭 올랐다. Hit@5 30/30과 범위 밖 거절 5/6은
유지됐으며, 정상 질의 2개는 1위에서 4위로 내려갔다. Qdrant·Chroma의
리랭커 집계 결과는 같았다. 이번 결과만으로 운영 하한을 확정하지 않는다.

## 실행 조건

- 실행 기준 코드: `ab801fd2cfb445782b7a142d21ac300091be91c1`와 이번 평가 CLI 변경.
- 문서: `data/eval/rag_documents_v1.toml`의 PDF 3종. 운영 DB·색인은 사용하지 않는다.
- 질의: `data/eval/rag_queries_v1.toml`의 정상 30개, 범위 밖 6개, 합계 36개.
- 임베딩: `BAAI/bge-m3`, 리비전 `5617a9f61b028005a4858fdac845db406aefb181`.
- 리랭커: `BAAI/bge-reranker-v2-m3`, 리비전 `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`.
- 청킹 기본 설정: 문자 기준 크기 1,000, 겹침 150. 구조 기반은 문맥·제목 길이를
  본문 가용 크기에서 빼며, 기존처럼 표 행 보존을 우선한다.
- 임베딩은 CPU, 문서 배치 8, 벡터 정규화를 사용한다.
- 후보 30개, 최종 K=5, 관련도 하한 `0.02`를 양쪽 모두 고정한다.
  이번 비교에서 하한을 재선정하거나 운영 기본값을 바꾸지 않는다.
- 최종 비교는 리랭커 추론 배치 2, 질의 임베딩 사전 계산 후 모델 참조 해제를
  양쪽 모두 적용한다. 후보 수나 입력 길이는 줄이지 않는다.
- `legacy`·`structured` 각각 Qdrant 로컬·Chroma의 독립된 임시 저장소에서 실행한다.
- CPU 실행, `OMP_NUM_THREADS=4`, `MKL_NUM_THREADS=4`,
  `TOKENIZERS_PARALLELISM=false`. 캐시된 모델만 사용하도록
  `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`을 지정한다.
- 실행 중 임베딩 캐시 사용. 동일 실행의 백엔드 간 임베딩을 재사용하므로
  처리 시간을 청킹 방식·백엔드의 속도 우열로 해석하지 않는다.

재현 명령은 [청킹 비교 안내](../CHUNKING_COMPARISON.md)의 실제 모델 검색 품질 비교를 따른다.

## 평가 해석

- 정답 판정은 기대 문서와 본문 키워드의 일치이며, 전체 정답 청크를 대상으로 한
  엄밀한 Recall@K나 전문가의 의미 검증은 아니다.
- 구조 기반 청킹은 문맥 머리줄·반복 제목을 추가한다. 이 문자열만으로 기대 키워드가
  일치할 수 있으므로 지표 변화와 함께 반환 근거를 확인해야 한다.
- 같은 36개 질의는 기존 하한 선택에도 사용됐다. 별도 검증셋의 성능으로 해석하지 않는다.
- 이번 실행은 문서 검색 평가다. Claude의 최종 답변·원인 판단 성능을 측정하지 않는다.

### 추가 문맥 머리줄 감사

모델 없이 같은 Indexer·평가 입력으로 파싱·청킹을 재현하고 본문을 보존했다.
구조 기반 청크 중 다음은 추가된 첫 `문맥:` 문단을 빼면 기대 키워드가 없었다.
이는 키워드 판정의 잠재적 영향을 찾는 검사이며, 해당 청크의 의미상 정답 여부를
판정한 것은 아니다.

| 질의 | 기대 키워드가 추가 문맥에만 있는 청크 |
|---|---|
| q09 | `BTT-SOP-001:1.1:0005` |
| q10 | `BTT-SOP-001:1.1:0009`, `BTT-SOP-001:1.1:0010` |

본문 감사 자료는 로컬 `outputs/rag_e2e/2026-10-30-chunk-audit.json`에 있다.
Qdrant의 실제 상위 반환 ID를 이 본문과 대조해 원본 보고서의 정답 순위를
재계산했고, 모든 정상 질의·검색 방식의 순위가 보고서와 일치했다.
추가 `문맥:` 문단을 제외한 같은 키워드 판정에서도 순위와 집계는 변하지 않았다.

| 구조 기반 Qdrant | 문맥 제외 Hit@1 | 문맥 제외 Hit@5 | 문맥 제외 MRR |
|---|---|---|---|
| Dense | 21/30 | 29/30 | 0.808 |
| Hybrid | 20/30 | 30/30 | 0.787 |
| 리랭커 | 24/30 | 30/30 | 0.878 |

따라서 이번 Qdrant 지표의 상승은 추가 문맥 문단의 키워드 일치만으로 생긴 것은
아니었다. 반복 제목을 포함한 의미상 정답 여부의 전문가 검증을 대체하지는 않는다.
Chroma는 원본 보고서에 질의별 반환이 저장되지 않아 이 본문 재집계 범위에 포함하지 않았다.
