# RAG 성능 평가 안내

검색·리랭킹·청킹·근거 부족 응답의 측정 기록은
[RAG 성능 평가](rag_e2e/README.md)에서 관리한다.

| 보고서 | 내용 |
|---|---|
| [검색·리랭킹](rag_e2e/retrieval-reranking.md) | Dense·Hybrid·리랭킹 비교, 관련도 하한, 백엔드·색인·갱신 검증 |
| [청킹 비교](rag_e2e/chunking.md) | 기존·구조 기반 청킹, 질의별 순위, 문맥 머리줄 영향 |
| [새 질문·챗봇 평가](rag_e2e/holdout-agent.md) | 24질문 하한 검증과 o02 실제 응답 검토 |
| [독립 질문 기준선](rag_e2e/independent-baseline.md) | 해시 임베딩·BM25, API 없는 20질문 평가 |

과거 BGE 모델 실측과 현재 해시·Voyage 구성을 구분한다.
공통 지표 정의·결과 요약·보완 과제는 평가 폴더의 안내 문서에 모았다.
원본 실행 출력은 `outputs/rag_e2e/`에 저장하고, 공유할 결과를 주제별 보고서에 반영한다.
이번 통합은 문서 정리이며 성능을 새로 측정한 결과가 아니다.
