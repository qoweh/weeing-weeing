# 센서 표본 보관

운영 설정에서 보관 작업을 켜면 DB 저장 후 3분이 지난 표본을 주기적으로 검토한다.
같은 공정·설비의 사건 최초 감지 시각 30초 전부터 정상 회복 시각 30초 후까지는
삭제하지 않는다. 회복 시각이 없으면 회복될 때까지 보존한다. 보고서 생성 전에도
근거가 사라지지 않도록 주의·경고 사건을 모두 보호한다. 여러 사건 구간은 합쳐서
보호하고, 처리 중 보고서가 없어도 사건이 남아 있으면 표본을 보존한다.

오래된 데이터도 정책 대상이다. 마이그레이션은 기존 행의 저장 시각을 이전에 알 수
없으므로 업그레이드 시점으로 설정하고 최소 3분 유예한다. 삭제는 일괄 1000건 이하로
나누어 이루어져 정확히 3분이 아닌 그 이후에 처리될 수 있다. 사건의 원본 표본 시각과
수신·저장 시각은 다른 값이며 정상 데이터의 만료에는 저장 시각을 사용한다.

이 정책은 사건 감지가 3분보다 늦게 생성되거나 삭제된 사건의 표본을 나중에 다시
요구하는 상황의 원본을 복구하지 못한다. 사건이 장시간 열려 있으면 해당 공정의 표본이
계속 남는다. 운영 적용 전에 DB 백업·복구 방법과 실제 분석 지연을 검증한다.
`TELEMETRY_RETENTION_ENABLED=false`로 향후 자동 삭제를 중지할 수 있지만 이미 삭제한
데이터는 되살리지 않는다.
