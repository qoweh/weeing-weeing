## 지금은 완료 처리하지 않는 항목

- **실제 색인/DB 스냅샷과 복원 검증**: 저장소의 `scripts/verify_rag_e2e.py`는 임시 저장소·임시 컬렉션을 만들고 정리한다. 현재 운영/평가 컬렉션의 지속 백업이나 #259 fixture를 자동 생성하지 않는다. DB·벡터 저장소 제품과 격리 대상을 지정하지 않은 채 백업 명령을 추측해서 실행하지 않는다.
- **실행 가능한 멀티 분석 평가**: E01~E10은 정답 승인을 받은 합성 사례 명세이며 실행기 입력이나 DB fixture가 아니다. 실제 fixture 연결과 통합 실행을 완료한 것처럼 기록하지 않는다.
- **50~80% 목표**: 실제 운영과 같은 설정에서 10건을 실행하기 전에는 통과율을 주장할 수 없다.
- **비밀 보호**: 이 목록은 API·`.env`를 읽거나 호출하지 않았다. 실제 유료 실행은 사용자가 본인 CMD에서 직접 하며, Codex에는 비밀을 제거한 설정과 결과만 제공한다.

## 안전하게 실행 가능한 남은 CMD 확인

출처 지문은 사용자가 이미 아래 값들을 실행해 기준값 일치를 확인했다. 반복 실행할 필요는 없다.

```cmd
git rev-parse HEAD
certutil -hashfile data\eval\rag_documents_v1.toml SHA256
certutil -hashfile data\manuals\BTT-MANUAL_v2.0.pdf SHA256
certutil -hashfile data\rulebase\BTT-RULE_v2.0.pdf SHA256
certutil -hashfile data\regulations\BTT-SOP-001.pdf SHA256
```

다음 CMD 작업은 1번에서 저장소 제품과 **격리 대상**을 정한 뒤에만 구체화한다. 그 전에는 인증값을 요구하거나 실제 운영 DB·컬렉션을 건드리지 않는다.
